# CoTeacher Product Specification

## Product vision
CoTeacher is a production-ready SaaS platform designed to reduce repetitive administrative work for Philippine public school teachers.

Core principle: **Enter information once. Reuse it everywhere.**

## MVP modules
1. Dashboard
2. Teacher Profile
3. Task & Deadline Manager
4. Document Management
5. Configurable Document Template System
6. AI Document Assistant
7. AI Lesson Planner
8. Contextual AI Assistant
9. Authentication & Authorization
10. Security & Privacy
11. Responsive UX/UI
12. Testing and production readiness

## Definition of done
A feature is complete only when functionality, persistence, authorization, error/loading states, responsive behavior, testing, and manual verification have been completed. Compiling code alone is not sufficient.

## Product rules
- Do not invent official DepEd requirements or forms.
- Do not hard-code potentially outdated DepEd policy.
- AI-generated content must be presented as draft content requiring teacher review.
- AI context must be explicitly scoped and must not cross user boundaries.
- Collect and retain only information necessary for the product.
- Build incrementally and verify each phase before starting the next.
