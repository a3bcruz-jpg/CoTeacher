# Curriculum Knowledge Layer

Curriculum records must be traceable to a verified source before they are presented as authoritative.

Required fields:
- `id`
- `gradeLevel`
- `learningArea`
- `competency`
- `source`
- `verified`

Optional:
- `quarter`
- `sourceUrl`

Do not import AI-generated competencies as verified records. Data ingestion should preserve source provenance and be reviewed before publication.
